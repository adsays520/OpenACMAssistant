# 架构搜索对照实验

本入口将方法、候选空间、随机性、代理评价与实测验收分开记录。支持8/16位原生近似乘法器的random、原NSGA-II和LLM方法对照，固定器件，暂不包含经验消融或SRAM对照。

## 连续语言使用

先输入：

> 开展8位近似乘法器的架构搜索对照实验，要求MRED≤0.02，目标为PDP最小。

随后补充：

> 算术测试固定为种子42、采样4096组；所有方法使用相同的综合库、5ns输入活动周期和10fF输出负载。将搜索随机种子与测试输入种子分开，每种方法重复5次，每次最多评价32个不同架构。

也可将两段合为一句。预算与重复次数缺失时只询问缺项，保留上文；不把第一次简略要求直接变成15轮默认执行。需要先预览时，在补充条件前加`/plan `，之后说“开始运行”。默认方法为随机/原NSGA-II/LLM；搜索种子1–5、池种子1729。未明确误差阈值时不擅自加MRED≤0.02。

命令行：

```bash
./openacm-assistant.sh compare --spec examples/compare-multiplier-8bit.json --plan-only
./openacm-assistant.sh compare --spec examples/compare-multiplier-smoke.json
./openacm-assistant.sh compare --spec examples/compare-multiplier-8bit.json
```

第一条只预览；第二条三种方法各一轮、每轮3架构及1次复核；第三条是各5轮、32架构、最多3次复核的正式规模。退出旧chat再启动即可载入新代码。

## 公平条件与含义

| 项目 | 默认正式规格及实际执行 |
|---|---|
| 电路与基线 | 8位原生近似，9位置全部AKbar2；各轮先评价相同基线 |
| 共同候选池 | 256项唯一分配，包含基线、同型与单位置变异、独立随机混合；固定池种子1729及SHA256 |
| 架构预算 | 每轮最多32个不同架构，包含基线；重复提案不重复评价 |
| 搜索随机性 | 搜索种子1、2、3、4、5，三种方法按种子配对，并轮换方法顺序 |
| 评价输入 | seed=42、4096组，其中有固定边界输入；各worker的实际vectors.hex哈希相同 |
| 目标与约束 | 预测阶段在MRED≤0.02约束下最小化预测PDP；最终实测重新验收MRED与实际PDP |
| 实测复核 | 每轮同规则选最多3项，重新执行RTL、综合、门级对照、STA/VCD活动功耗；预测无可行项时复核最低预测MRED候选 |
| 物理条件 | 同一Nangate45 typical库及哈希；5ns活动周期、10fF输出负载；器件固定 |
| 提案机制 | NSGA-II在共同池索引上演化，LLM从共同池中的最多12项菜单选点，随机从共同池直接抽取 |
| 经验与故障 | 不注入持久经验或其它轮结果；LLM失败保留为失败轮次，不随机回退冒充LLM |
| 时间 | 默认整管线7200秒、每轮1800秒；达到时间则incomplete，实际数按记录呈现 |

每轮32次架构评价是PEA-GNN查询，不是32个电路都跑过真实EDA；最多3个入选项分别实测。有限池对照只针对上述具体策略，不等于所有全基因NSGA-II或所有LLM方案的优劣比较。GNN原训练PPA条件与本地综合未证实完全一致，差异不直接称同分布泛化误差。

## 查看进展与结果

`runs/<时间>_search_comparison_<ID>/result.json`保存已结束轮次与active_trial；`logs/pipeline.log`记录各轮进度。每轮在`trials/seed_<n>/<method>/`中独立保存result、config、conditions、stages和decisions。

`reports/summary.md`直接给中文完成数与各方法实测统计；`report.md`列所有轮次，`trial_summary.csv`可导入表格，`search_curves.csv`逐点保留预测最优轨迹，`statistics.json`保留完整/可行分母及中位数、标准差。结束输出`prediction_search_curve`和`measured_final_comparison`各PNG/SVG/PDF，预测与实测图分开。

失败、无可行项、未完成轮次不能按0填入图或从分母删掉。五次重复并不自动证明统计显著优越。报告模型/EDA实际计数与墙钟成本，整管线另含共享模型初始化和汇总开销。原始程序只读，所有新配置、RTL、日志、决策和图在该专属任务目录，不改旧任务结果。

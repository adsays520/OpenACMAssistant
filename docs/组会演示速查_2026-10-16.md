# OpenACMAssistant 组会演示速查

配合[完整汇报文档](组会汇报_2026-10-16.md)使用。建议主讲 15–20 分钟，现场演示约 4 分钟；长探索和后端展示历史实测。

## 1. 会前准备

```bash
cd /data2/huangjj/OpenACMAssistant
export OPENACM_SOURCE=/data2/huangjj/OpenACM
export OPENACM_OLLAMA_URL=http://127.0.0.1:11435
export OPENACM_MODEL=deepseek-script
./openacm-assistant.sh doctor
```

模型服务未启动时执行：

```bash
/data2/huangjj/DeepSeekLocal/deepseek.sh start
/data2/huangjj/DeepSeekLocal/deepseek.sh status
```

`doctor` 只查工具路径和 Landlock，不代表模型推理和许可证已验证。会前完整试跑一次以下短流程。

## 2. 中文需求 → 计划 → 真实执行

```bash
./openacm-assistant.sh chat --theme ocean
```

在聊天中逐行输入：

```text
你能干什么？
MRED是什么意思？
/plan 做4位精确乘法器，穷举所有输入
开始运行
刚才结果是否达标，验证了多少组输入？
/exit
```

讲解要点：咨询不运行 EDA；计划不等于实测；4 位穷举共 256 对，报告以实际结果为准。

## 3. 回放近似设计与 ASIC 后端

回到 Bash：

```bash
./openacm-assistant.sh summarize runs/20261010_144052_multiplier_e7ddb8 --no-model
./openacm-assistant.sh summarize runs/20261010_144501_full_flow_89aabc/tasks/20261010_144602_dcim_5d0d64 --no-model
```

第一项：穷举 MRED≈0.01422≤0.02；综合面积 291.802 µm²。允许误差不等于零错误。  
第二项：setup=4.64506388 ns，hold=0.03318188 ns，详细布线 DRC=0；路由面积 7800 µm²。  
这是历史任务回放，不重新执行 EDA；会更新总结审计。完全只读时在 IDE 打开对应 `result.json`。

## 4. 展示经验和公开参考

```bash
./openacm-assistant.sh memory stats
./openacm-assistant.sh memory query --spec examples/explore-multiplier.json --limit 3
./openacm-assistant.sh dataset query --spec examples/explore-multiplier.json --limit 3
```

本次统计：761 条当前本地观测；公开数据 50,000 个唯一配置。外部标签与本地实测独立管理，检索不更新模型权重，候选仍须复测。

## 5. 可选：小预算探索

有足够时间才启动；120 秒是预算，不承诺跑满 8 个或找到达标项：

```bash
./openacm-assistant.sh explore --spec examples/explore-multiplier.json --budget 8 --max-seconds 120
```

展示 `report.md` 的实际执行数、最佳可行项、停止原因，以及 `history.csv` / `decisions/`。长探索结果可打开 `runs/20261010_143300_explore_dcim_e42ef3/report.md`。

模型不可用：执行第 3 步，再打开 `runs/20261011_194033_dialogue_validation/report.md`，明确展示历史对话证据。工具失败：查看新任务 `logs/` 和 `result.json`，按真实失败报告。

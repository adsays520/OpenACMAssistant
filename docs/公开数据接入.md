# 公开8位乘法器数据接入

已下载并核验[公开数据集](https://huggingface.co/datasets/xuzhuo0417/openacm-gnn-8bit-dataset)，固定快照`72a0ad0ea83d5b724999c6c1a66d8e57fda7c1d1`。20个文件、14,229,225 bytes；包含50,000个不同配置、每配置9个压缩器选择及MRED/NMED/delay/area/power标签，另有图、特征和模型附件。

本次接入为**本地检索增强**：外部执行器检索相关配置与标签，随需求规划或探索决策请求发送给本机Ollama/DeepSeek。没有训练或修改DeepSeek/GNN权重，也没有替换原工程GNN。下载的Python文件仅作来源资料和AST静态核对，不执行；权重仅保留归档。

## 目录与命令

所有数据位于`datasets/openacm-gnn-8bit/`，不会写入原始OpenACM，也不会加入Git。布局为：

```text
repository.json                 上游仓库元信息
download_manifest.json          固定版本、URL、大小、SHA256
source/                         原始20个文件
derived/samples.sqlite3         本地检索索引
derived/observations.jsonl       模型无关的全部配置/标签交换文件
audits/compatibility.json        压缩器映射及本地GNN对照
audits/validation.json           全量核验、标签统计与划分策略
audits/compressor_truth/         RTL真值表核验产物
audits/local_model_validation.json  最新本地模型/仿真验证任务
```

```bash
./openacm-assistant.sh dataset fetch       # 拉取固定公开快照
./openacm-assistant.sh dataset prepare     # 文件SHA、配置、标签、归一化、图、RTL映射核验
./openacm-assistant.sh dataset status
./openacm-assistant.sh dataset query --spec examples/explore-multiplier.json
./openacm-assistant.sh dataset verify      # DeepSeek实际选择，3配置RTL/综合/门级对照
```

`dataset verify --without-model`只作确定性复测，不能作为模型使用数据的证明。`OPENACM_PUBLIC_DATA=0`关闭自动参考检索；数据继续保存在本地。

## 模型与探索怎样使用

- 需求规划：8位近似乘法器按明确参数检索相关参考，不能覆盖用户参数；明确固定全部sabetz时只查该一致配置，若未收录则不使用其它配置替代。
- 默认探索：仅当逐位置分配是可调整变量时，最多加入32个训练样本的配置向量；每轮优先提供至多3个允许的公开候选，并保留其它探索方式。第一轮仍为原基线。
- 自定义`--spec`与续跑：尊重保存的搜索域，不能偷偷加入域外值；参考可以帮助模型判断探索方向。固定尺寸、测试向量、种子和后端保持原规则。
- 模型请求带`public_dataset_reference`，最多6条相关观测，标记`external_reference_only`和`locally_measured=false`。候选实际测量仍独立执行，排名只使用真实结果。
- 公开候选的输出理由由来源字段整理成“参考样本X，选择菜单Y复测，本地是否达标待验收”。模型原始文字保留在`reply.json`和`reason_grounding.json`，避免把模型“已达标”的猜测写成验收结论。
- 新启动的规划/探索会加载接入代码；已经运行的旧进程不会自动热加载。旧任务结束后可续跑，或启动新探索。原有运行目录不会被改写或清除。

规划目录保留`public_dataset_retrieval.json`；探索保留任务级和逐轮检索记录，以及`menu/request/reply/selection`。交换JSONL包含来源、版本、原始配置、映射配置、split、原始/归一化标签和未知评价条件。其它模型可使用相同结构，验证/测试数据不应进入决策提示词。

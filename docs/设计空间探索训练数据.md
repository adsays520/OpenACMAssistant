# 设计空间探索的训练数据

先明确要改善的环节：代理模型负责预测候选指标，LLM负责理解需求和选择下一步，EDA负责提供实测及最终验收。当前持久经验库积累观测，尚未执行GNN或LLM训练。

## 代理模型样本

基础样本为“电路配置/图结构 + 评价条件 → 实测标签”。以8位近似乘法器为起点，可包含：

| 字段 | 含义 |
|---|---|
| bit_width、architecture、kind | 位宽、native/tiled结构、精确/近似类别 |
| compressor_ids | 每个位置的压缩器类型；位置顺序按实际生成器定义 |
| nodes/features、edges | 用GNN时提供节点特征、连接关系；需要与实际电路对应 |
| samples、seed、exhaustive | 精度测量采用的测试集合及覆盖方式 |
| source/runner/library/tool fingerprints | 实现版本及评价环境 |
| synthesized_area_um2 | 综合映射面积；区别于路由面积和启发式面积 |
| mred、nmed、error_rate | 独立RTL参考比较得到的误差标签 |
| delay/power（若已测） | 明确库、负载、时钟/活动、PVT与测量阶段的时延和功耗 |
| status、evidence、quality_issues | 执行是否完成、数据来源及标签质量 |

GNN并非必须：固定拓扑下可以先采用配置向量作为输入；研究连接结构或不同拓扑时可使用电路图。PyTorch Geometric的常见图数据字段为节点特征x、连接edge_index、标签y，见[官方图数据说明](https://pytorch-geometric.readthedocs.io/en/latest/get_started/introduction.html)。

原工程8位GNN的predictor输出5项 `[MRED,NMED,Delay,Area,Power]`；图阶段节点与全连接层尺寸固定，对应已有8位结构，不能直接假定适用于4–64位或分块结构。工程也有独立16位预测器。Graph.csv和FEATURE.csv提供图/特征信息，label_minmax文件提供标签缩放信息，它们不能替代逐配置的真实测量标签。GNN的0–7状态与助手1–8压缩器ID需要核对类型及位置映射，不能未经核验直接转换。

当前助手的整数综合探索主要产出面积和误差；缺少同配置的延迟/功耗标签时，先训练实际具备标签的目标，或补跑明确的评价流程。不能用压缩器单元功耗填乘法器功耗，也不能把DCiM整体宏面积填入乘法器面积。

已拉取公开的50,000配置8位乘法器数据，核对0–7到1–8压缩器真值映射、全部配置与原始标签，接入本地模型检索。公开标签与本地复测存在明显差异，不能直接并入同条件训练集；详情及可交换JSONL见[公开数据接入](公开数据接入.md)。当前仍未执行GNN或LLM权重训练。

## LLM选择样本

样本输入应包含当前用户目标、硬约束、允许搜索空间、截至该决策时已测的候选、候选菜单；输出为合法候选选择及基于已有证据的说明。后续仿真结果用于核验这次选择的效果，不应提前泄漏到输入中。

现有decision目录中的menu/request/reply/selection和候选result可以作为素材。模型原reason可能错误声称未测配置已经达标，不能原样作为标准答案；格式合法也不等于选择质量良好。数据需要去重、核验约束、补充有依据的选择标签，并与保持预算一致的确定性/随机基线比较。

指令微调通常采用prompt/completion或messages格式，见[TRL SFT文档](https://huggingface.co/docs/trl/sft_trainer)。需要偏好训练时可构建同一输入的chosen/rejected对，见[TRL DPO文档](https://huggingface.co/docs/trl/main/dpo_trainer)；偏好应按明确目标、约束和实测依据标注，不以模型“说得像正确答案”为准。

## 数据质量与评估

- 未满足设计约束但仿真完成的配置仍可提供有效回归标签，例如真实MRED超标；编译失败、超时或缺测不能填0作指标标签。
- 区分电路功能问题和工具/资源失败，不把一次超时自动标成电路不可行。
- 不同位宽、架构、工艺库、PVT、测试集合、综合/路由口径分别管理。已有旧任务缺少环境元信息，需先核对来源，不能直接混入同条件训练集。
- 按配置或结构族去重和划分训练/验证/测试，相同配置及紧密重复试验不能分到不同集合；保留未见配置评价泛化和约束判断。
- 代理模型先评价指标误差及候选排序，再检查它是否在固定仿真预算下找到更好的可行设计；最终候选实际仿真，不将预测当验收。
- 数据量按有效、独立、同范围且有目标标签的配置统计，不能把运行次数或测试向量数当配置数。

可采用“LLM提出候选 → 代理模型预测/筛选 → 部分候选真实仿真 → 观测入库 → 周期性重新训练”的流程。当前已实现真实探索和持久观测积累；代理模型训练、重训调度及预测筛选需要后续接入。

# 拍摄用逐条输入

每条单独输入并等待回复。与[已验证问句](拍摄问句验证报告.md)一致，场景之间 `/new`，场景内连续交流。完整分镜、解说与素材见[拍摄流程](新版参赛视频拍摄流程.md)。

## Bash：启动

```bash
cd /data2/huangjj/OpenACMAssistant
export OPENACM_SOURCE=/data2/huangjj/OpenACM
export OPENACM_OLLAMA_URL=http://127.0.0.1:11435
export OPENACM_MODEL=deepseek-script
./openacm-assistant.sh chat --theme ocean
```

## Chat：能力与短仿真（实际运行）
